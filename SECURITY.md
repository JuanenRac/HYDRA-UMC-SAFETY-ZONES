## Reporting a Vulnerability

**CRITICAL: Do not report safety-critical vulnerabilities through public GitHub issues.**

In a safety-critical system, a security flaw is a direct physical hazard. If you discover a vulnerability affecting the **intrusion detection logic**, **CAN E-STOP frames**, or **zone masking bypasses**:

1. **Email**: Send a detailed report to `electrohobby3d@gmail.com`.
2. **Impact**: Describe if the bug allows disabling the E-STOP, spoofing occupancy maps, or causing false positives that lead to hardware wear.
3. **Response**: Initial acknowledgment within 48 hours.

We follow a coordinated disclosure policy to ensure hardware safety before public release.
